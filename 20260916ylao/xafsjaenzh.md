# 山西医科大学第一医院/第一临床医学院分获山西医科大学第五十九届运动会教工组及学生组团体冠军

5月16日，山西医科大学第五十九届运动会圆满闭幕。山西医科大学第一医院在院党政的大力支持下，院工会和团委精心组织，全院职工和学生踊跃报名、积极参与、团结协作，运动健儿努力拼搏、奋勇争先，最终以461.5分的总成绩蝉联校运会教工组团体冠军，以277分的总成绩蝉联学生组团体冠军。

一院教工代表队由54人组成，从4月19日至5月12日每日下班后进行赛前集训，参加了教工组全部比赛项目。最终在6项集体项目中夺得5个冠军、29项个人项目中夺得19个冠军，彰显出一院职工勇于拼搏的斗志。

<<  滑动查看下一张图片  >>

第一临床医学院学生代表队由78名运动员组成，进行了38天的集中训练，圆满完成了25项个人及团体比赛。比赛中，2019级五年制的武韵佳同学以5分34秒84的成绩，打破保持了十年的校运会女子1500米记录。同时，从去年到今年陆续开展的气排球赛、师生羽毛球赛、足球赛、篮球赛、啦啦操赛以及2020级男子引体向上和女生800米测试，均按照不同的分数占比计入山西医科大学体育工作风采项目，最终第一临床医学院学生以总分137.5分荣获院系体育工作风采第一名。

<<  滑动查看下一张图片  >>

此外，在运动会期间第一临床医学院学生衣着统一、遵守纪律，积极参与微博、超话以及宣传稿的报送，展现出蓬勃向上的良好风貌，最终荣获山西医科大学第五十九届运动会学生组精神文明奖。
